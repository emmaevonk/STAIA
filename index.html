📦 STAIA

STAIA is a Python package for spatial transcriptomics with its aim to lower the computational barrier. The software is currently focused on Xenium data from 10X Genomics.

ℹ️ Overview

STAIA is a Python package for analyzing spatial transcriptomics data. It provides a Command Line Interface (CLI) to perform quality control, spatial statistics, neighborhood analysis, and visualization for datasets generated with the Xenium platform from 10X Genomics.

The API is designed around a clean, functional workflow:

STAIA.function()

This makes it easy to build reproducible spatial analysis pipelines with minimal boilerplate.

Link to the GitHub page: (https://github.com/emmaevonk/STAIA)
