⬇️ Installation

Simplified installation

Currently, STAIA is not yet available on Pypi.

Installing from the source:

conda create -n "STAIA" python=3.11 ipykernel
conda activate STAIA
export PYTHONNOUSERSITE=1

git clone https://github.com/emmaevonk/STAIA.git
cd STAIA
pip install -r requirements/requirements_CPU.txt --no-cache-dir --extra-index-url https://download.pytorch.org/whl/cpu -f https://data.pyg.org/whl/torch-2.6.0+cpu.html
pip install "pybanksy[notebooks]" --no-cache-dir
pip install -e . --no-cache-dir
python -m ipykernel install --user --name STAIA --display-name "STAIA"

If a GPU is available, change the requirements/requirements_CPU.txt to requirements/requirements_GPU.txt

Minimum requirements: look at requirements_v2.txt file

After running installation, STAIA can be imported by running import STAIA.

Installation CPU

STAIA is meant to be run from a conda environment, so create one:

conda create -n "STAIA-env" python=3.11 ipykernel

The conda environment is built with python 3.11, because the latest version of BANKSY (which is integrated in this package), does not support newer Python versions (yet). Now it's time to activate the environment and double check the python version present in the environment:

conda activate STAIA-env
python --version

When working on an HPC, the home folder has limited space and can therefore be occupied very fast. Run this command to prevent this from happening when using an HPC (if not, this can be ignored):

export PYTHONNOUSERSITE=1

The STAIA package is not (yet) available on the Python Packaging Index (Pypi), so the repository needs to be cloned from github:

git clone https://github.com/emmaevonk/STAIA.git
cd STAIA
pip install -r requirements_CPU.txt --no-cache-dir --extra-index-url https://download.pytorch.org/whl/cpu -f https://data.pyg.org/whl/torch-2.6.0+cpu.html
pip install "pybanksy[notebooks]"

Now all necessary packages to run STAIA have been installed. Run ipykernel to make sure you can use the environment as a kernel in a Jupyter Notebook:

python -m ipykernel install --user --name STAIA-env --display-name "STAIA-env"
